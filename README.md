# Copper For Change Co. Website

This repository contains the source code for the official Copper For Change Co. website.  
The site is built using HTML, CSS, and JavaScript and is hosted using GitHub Pages.

## 🌐 Live Website
Custom Domain: https://mifei.co.uk  
GitHub Pages URL: https://mifei.co.uk.github.io/CopperForChangeCo

## 📁 Project Structure
- index.html — Main homepage
- css/ — Stylesheets
- js/ — JavaScript files
- assets/ — Images, icons, and media
- README.md — Project documentation

## 🚀 Deployment
This site deploys automatically using GitHub Pages.

To update the website:
1. Edit your files locally or directly in GitHub.
2. Commit and push changes.
3. GitHub Pages will rebuild and update the live site.

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  
- GitHub Pages (Static Hosting)
